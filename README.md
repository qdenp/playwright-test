# Practice -- песочница для локального агента

Стек: .NET 10, xUnit, Shouldly, NSubstitute.
Агент: Roo Code + Ollama (`qwen2.5-coder:7b`), локально, без интернета.

## Настройка Roo Code (один раз)

Иконка Roo Code слева -> шестерёнка -> **Providers**:

- API Provider: `Ollama`
- Base URL: `http://localhost:11434`
- Model: `qwen2.5-coder:7b`

Режимы (`Test Author`, `Code Critic`, `Explainer`) подхватятся из `.roomodes`
автоматически. Правила -- из `.roo/rules/csharp.md`.

## Упражнение 1 -- твоя сильная сторона

`src/Practice.Core/BookingOverlap.cs` содержит **реальный дефект**
в граничном условии. Спецификация -- в комментарии над классом.

1. Режим **Code Critic** -> попроси найти дефект.
2. Проверь его вывод сам: критик может промахнуться и может выдумать.
3. Режим **Test Author** -> красный тест на смежные интервалы.
4. `dotnet test` -- тест должен упасть.
5. Починить реализацию -- **руками**.
6. `dotnet test` -- зелёное.

## Упражнение 2 -- твой пробел

`src/Practice.Core/DurationFormatter.cs` -- пустая заготовка,
спецификация в комментарии, тесты уже написаны и падают.

**Реализуй сам, без агента.** Агента подключи только после того, как твоя
версия стала зелёной -- в режиме **Code Critic**, чтобы поискал дефекты
в твоём коде.

Это и есть тренировка кодинг-гейта: писать руками, потом проверять агентом,
а не наоборот.
